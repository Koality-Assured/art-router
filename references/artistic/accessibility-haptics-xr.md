# Accessibility, haptics, and XR source capture

This page records five official sources for digital publication accessibility, tactile and haptic interaction, and OpenXR-based work. Each source keeps its own scope and status. Statuses were checked on 8 October 2026.

## Source records

### EPUB Accessibility 1.1

- **Proposed source ID:** `w3c-epub-a11y-11`
- **Official page:** [EPUB Accessibility 1.1](https://www.w3.org/TR/epub-a11y-11/)
- **Publication status:** W3C Recommendation, published 17 October 2024.
- **Capture:** The specification covers content conformance and accessibility discoverability for EPUB publications. It describes accessibility metadata and explains how to evaluate WCAG across a publication, with additional EPUB-specific requirements and reporting.
- **Scope:** Apply this source to EPUB publications. It does not define a general checklist for standalone images, audio, or XR scenes.

### EPUB Accessibility 1.2

- **Proposed source ID:** `w3c-epub-a11y-12-crd`
- **Official status page:** [W3C epub-a11y series](https://www.w3.org/TR/epub-a11y/all/)
- **Version page:** [EPUB Accessibility 1.2](https://www.w3.org/TR/epub-a11y-12/)
- **Publication status:** W3C lists version 1.2 as a Candidate Recommendation Draft dated 12 September 2026. The page identifies 21 July 2026 as its latest Candidate Recommendation snapshot.
- **Capture:** As of capture, 1.2 remains a draft, while 1.1 is a Recommendation. Recheck the status before relying on draft text.

### ISO 9241-910:2011

- **Proposed source ID:** `iso-9241-910-2011`
- **Official page:** [ISO 9241-910:2011](https://www.iso.org/standard/51097.html)
- **Publication status:** ISO’s listing displays stage 90.93 (Confirmed); the dated confirmation milestone is 30 June 2022.
- **Capture:** The catalog title is “Ergonomics of human-system interaction — Part 910: Framework for tactile and haptic interaction.” This page stores bibliographic and status metadata only.

### ISO 9241-920:2024

- **Proposed source ID:** `iso-9241-920-2024`
- **Official page:** [ISO 9241-920:2024](https://www.iso.org/standard/80751.html)
- **Publication status:** Current published requirements-and-recommendations document; ISO lists edition 2 and publication month 2024-10. Its lifecycle records stage 60.60 and publication date 2024-10-11. ISO marks ISO 9241-920:2009 as withdrawn.
- **Capture:** This entry contains bibliographic and status metadata only. No requirements or clauses are paraphrased.

### ISO source-use boundary

The ISO product pages state that ISO content may not be used for AI or machine learning outside ISO Open Data terms, and direct copyright requests to written permission. This page keeps both ISO entries to bibliographic and status metadata. Recheck the posted terms before any further use.

### OpenXR 1.1

- **Proposed source ID:** `khronos-openxr-1-1`
- **Official registry:** [Khronos OpenXR Registry](https://registry.khronos.org/OpenXR/)
- **Current specification page:** [OpenXR 1.1 API and published extensions](https://registry.khronos.org/OpenXR/specs/1.1/html/xrspec.html)
- **Haptic API reference:** [`xrApplyHapticFeedback`](https://registry.khronos.org/OpenXR/specs/1.1/man/html/xrApplyHapticFeedback.html)
- **Version record:** The official registry’s ratified-extension edition, [OpenXR 1.1 with ratified extensions](https://registry.khronos.org/OpenXR/specs/1.1-khr/html/xrspec.html), identifies itself as version 1.1.63. The registry’s 1.1 entry and its current specification pages reported 1.1.63 at retrieval on 8 October 2026.
- **Capture:** The registry provides the OpenXR API specifications and related implementation references. Use this reference for technical integration questions about OpenXR-based XR work. Use sources designed for artistic or accessibility evaluation when those questions arise.

## Use limits

The retrieval date for every record is 8 October 2026. Recheck the linked official pages before relying on a status. To assess an artwork against accessibility, safety, or other requirements, select the applicable source and evaluate the artifact.
