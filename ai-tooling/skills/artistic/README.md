# Artistic skills

Portable workflows for creating artwork and reviewing requests, routes, and package evidence. The three review skills are read-only and owned by `artistic-standards-reviewer`. The separate, write-capable production workflow is owned by `artistic-production`.

- [`evidence-validation/`](./evidence-validation/): check manifest declarations, handoffs, and fixity.
- [`representation-routing/`](./representation-routing/): choose applicable representation rows and shared controls.
- [`request-contract/`](./request-contract/): normalize the brief, preserve constraints, and check execution drift.
- [`production-workflow/`](./production-workflow/): create artwork and package outputs using declared host capabilities.
